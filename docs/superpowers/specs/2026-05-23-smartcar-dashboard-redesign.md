# Smart Car Dashboard 网页重设计 spec

日期: 2026-05-23 | 版本: v1

## 背景

智能小车通过 UDP 接收主板图像帧和状态数据，WebSocket 推送到网页端实时展示。原始页面（`3cecedc`）4509 行，数据齐全但信息层级混乱。当前版本（`79804c4`）精简到 474 行，大量数据丢失。需要在信息密度和可读性之间找到平衡。

**核心使用场景**：80% 调试（视觉调试 + 车控调试），20% 驾驶监控。调试时图像和参数需要同屏对照分析。目标分辨率 1820x1200，一页无需滚动。

## 架构总览

```
┌───────────────────────────────────────────────────────────┐
│ [驾驶] [视觉] [车控]          │ 帧率 连接  │ ⚙参数  ⏺录制 │
├──────────────┬────────────────────────────────────────────┤
│              │  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐      │
│ 灰度图       │  │主状态│ │子状态│ │转速L│ │转速R│ │速度 │      │
│ 320x240      │  └────┘ └────┘ └────┘ └────┘ └────┘      │
│              ├────────────────────────────────────────────┤
├──────────────┤  ▼ 元素状态机详情                           │
│ IPM 透视图   │  ▼ 绕行状态机详情（无ROI图）                │
│ 400x120      │  ▼ PID 参数详情(L/R)                       │
│              │  ▼ 陀螺仪数据                               │
├──────────────┤  ▼ dir 数组                                │
│ 叠加开关:    │  ▼ 传输状态详情                             │
│ ☑边界 ☑中线  │                                            │
│ ☑锚点 ☑dir   │                                            │
│ ☑采样点      │                                            │
└──────────────┴────────────────────────────────────────────┘
```

- 左列 28-30%：灰度图(上) + IPM 透视图(下) + 叠加开关(底部)
- 右列 70-72%：L1 核心卡片行(固定顶部) + L3 折叠面板区(下方，内部滚动)
- 顶部工具栏：三预设切换 + 帧率 + 连接状态 + 快捷调参入口 + 录制按钮

## 数据三级分层

### L1 核心卡片（始终可见，大字展示）

| 预设 | 卡片内容（5-6个） |
|------|-------------------|
| 驾驶模式 | 主状态、子状态、左转速、右转速、基础速度、帧率 |
| 视觉调试 | 主状态、子状态、绕行状态、推理置信度、中线数量、传输帧率 |
| 车控调试 | 主状态、子状态、基础速度、差速度、目标角速度、陀螺仪角速度 |

### L2 图像+叠加（左侧固定）

- 灰度图（~320x240，原分辨率不拉伸浪费）
- IPM 透视图（~400x120，按有效数据行数裁剪，大部区域无数据不撑大）
- 图像叠加开关：边界数组、中线、锚点圆、采样点模式、八邻域 dir 图

### L3 折叠详情（按需展开，展开区域内部滚动）

| 面板 | 内容 |
|------|------|
| 元素状态机详情 | 主/子状态名、首选来源、编码器计数、直道焦点（中线count, lastIndex, errorSum, errorMax）、十字焦点（角点坐标, gap_x, aux, 各阶段ready）、下一状态预测、各状态计数器、边界数组 |
| 绕行状态机详情 | 绕行主/子状态名、推理结果（分类概率列表）、帧墙数据（注意：ROI 图不展示，后续推理结果由视觉下位机串口发送，主板上位机判定绕行状态） |
| PID 参数详情 | 公共 PID(Kp/Ki/Kd)、左轮 PID、右轮 PID、目标角速度、yaw_rate_ref、减速方案多分支参数（exp_lambda, split_ratio, error_scale, winner_branch, final_scale, realtime_speed） |
| 陀螺仪数据 | 当前角速度、加速度、角度数据 |
| dir 数组 | 八邻域方向数组、trace dir 图 |
| 传输状态详情 | 速率(Mbps/KiB/s)、各通道帧率(gray/rgb/binary 分别)、同步状态、CPU%、内存% |

### 三预设默认展开策略

| 预设 | 默认展开 | 默认折叠 |
|------|---------|---------|
| 驾驶模式 | 无 | 全部折叠 |
| 视觉调试 | 元素状态机详情、绕行状态机详情、dir 数组 | PID、陀螺仪、传输状态 |
| 车控调试 | PID 参数详情、陀螺仪数据 | 元素状态机、绕行状态机、dir 数组、传输状态 |

## 功能清单

### 1. 实时图传与数据刷新
- UDP 接收图像帧 + WebSocket 推送全部状态数据（复用 v1 的数据管道）
- 三预设一键切换 L1 卡片和默认展开面板
- 6 个可折叠详细面板，展开在区域内滚动不撑开页面

### 2. 录制回放
- 全量录制：图像帧 + WebSocket 全部状态数据，写入本地文件夹
- 回放复用仪表盘 UI：数据源从 WebSocket 切换为本地录制文件
- 播放控制条：暂停/快进/快退（每次 1 秒）/ 逐帧步进
- 保存录制到指定目录

### 3. 调参（双入口）
- **快捷面板**：仪表盘内点击齿轮图标 → 侧边栏弹出 → 常用 PID 参数滑块/输入框 + "应用"按钮（优先热更新，失败自动降级离线 SSH 写入）
- **完整配置页**：独立 `config.html`，TOML 编辑器 + 智能应用按钮 + 读取/比较/备份功能。保留全部 v1 config 页功能，但精简按钮（热更新+离线合并为一个智能按钮）

### 4. 图像叠加开关
- 灰度图/IPM 图上叠加：边界数组（左/右边界）、左右均值中线、锚点圆、采样点模式、八邻域 dir 图
- 全部以 checkbox 形式在左下角展示

### 5. 传输状态条
- 顶部常驻：帧率、连接状态 indicator、CPU%、内存%（简化版，详细数据在折叠面板）

## 数据流

```
主板 UDP → server.js (WebSocket broadcast) → 仪表盘实时渲染
                                           → 录制时同步写 status.json + 图像帧
                                           
录制文件 → server.js (本地文件读取) → 仪表盘回放渲染（复用同一 UI）

调参面板 → HTTP POST → server.js → 主板热更新 / SSH 离线写入
```

## 非目标

- 不做数据变更（保留 v1 的全部数据字段和 WebSocket 协议）
- 不做后端重构（server.js 保留 v1 数据管道）
- ROI64 图不再展示（后续推理由视觉下位机串口发送）
- 不做响应式/移动端适配（专为 1820x1200 桌面设计）
- 不在仪表盘内嵌完整 TOML 编辑器（保留独立 config.html）
