# 视觉处理全链路：八邻域巡线 → IPM 逆透视 → line_error

本文档描述从图像采集到最终控制量 `line_error` 的完整处理链路，基于当前代码（[vision_image_processor.cpp](../code/driver/vision/vision_image_processor.cpp)，约 5500 行）。

---

## 1. 整体数据流

```
采集 320×240 (或 160×120)
  │
  ▼
裁剪/缩放 → 160×60 BGR → 灰度 → OTSU二值化
  │
  ▼
起点搜索 (帧间历史自适应)
  │
  ├── 迷宫法 (4方向, 无dir) ──→ left_pts / right_pts ──────────┐
  │                                                              │
  └── 八邻域 (8方向, 有dir, 默认) ──→ raw trace                  │
         │                                                       │
         ├─ 统计 start_frame_wall_rows (给状态机)                 │
         ├─ trim 起始帧墙前缀                                     │
         ├─ 下角点方向模板检测                                     │
         ├─ extract_one_point_per_row → left_pts / right_pts     │
         └─ [CROSS] build_cross_aux_boundary                     │
                │                                                 │
                ▼                                                 │
         状态机 update (决定 sub_state)                            │
                │                                                 │
         [CROSS/CIRCLE 分支] 边界重构/桥接/外推                     │
                │                                                 │
                ▼                                                 ▼
         fill_boundary_arrays_from_maze() → g_xy_x1/x2/x3_boundary[]
                │
                ▼
         transform_boundary_points_to_ipm() → IPM空间 (160×100)
                │
                ▼
         IPM预处理: 去重 → 去毛刺 → [可选]等距重采样
                │
                ▼
         select_shift_source (LEFT / RIGHT / AUTO)
                │
                ▼
         shift_boundary_along_normal() → IPM平移中线
                │
                ▼
         可选后处理: 三角滤波 → [可选]等距重采样
                │
                ▼
         transform_boundary_points_from_ipm_to_src() → src回投中线 (仅供显示)
                │
                ▼
         vision_line_error_layer_compute() → line_error (IPM坐标)
```

---

## 2. 分支总览

整个链路存在 **5 个独立的分支维度**：

| 维度 | 选项 | 默认值 |
|------|------|--------|
| 二值化策略 | OTSU(0) / ADAPTIVE_MEAN(1) / ADAPTIVE_FULL(2) | OTSU |
| 边界追踪方法 | 迷宫法(0) / 八邻域法(1) | 八邻域 |
| 路径主状态 | NORMAL / CROSS / CIRCLE | NORMAL |
| IPM 中线源选择 | LEFT / RIGHT / AUTO | AUTO |
| line_error 采样 | FIXED_INDEX / WEIGHTED_INDEX / SPEED_INDEX / WEIGHTED_SPEED_DELTA | WEIGHTED_INDEX |

### 3.2 阶段 1：二值化

位置：[vision_image_processor.cpp:4086-4129](../code/driver/vision/vision_image_processor.cpp#L4086-L4129)

#### 分支 A：OTSU 大津法 (PRECOMPUTED, mode=0, 默认)

```
灰度图 → cv::threshold(OTSU) 全图阈值
       → filter_binary_image_inplace()  形态学闭运算
       → draw_binary_black_frame()       边缘画 1px 黑框 (x=0, x=159, y=0)
       → PixelClassifier::make_precomputed()
```

#### 分支 B：ADAPTIVE_MEAN (mode=1)

```
巡线时按需自适应阈值（惰性求值）
巡线完成后用收集到的阈值均值做全图二值化
```

#### 分支 C：ADAPTIVE_FULL (mode=2)

```
全图像素级自适应阈值 → 形态学滤波 → 黑框
```

**共同步骤**：所有分支最终都做形态学闭运算 + 图像四边 1px 黑色人工边框，确保巡线不会逃逸。

### 3.3 阶段 2：起点搜索

位置：[vision_image_processor.cpp:4131-4379](../code/driver/vision/vision_image_processor.cpp#L4131-L4379)

```
get_maze_trace_x_range_clamped()   搜索范围 [1, 158]
       │
previous_src_centerline_first_x()  上一帧中线首点 x → 回退中心
       │
find_maze_start_from_row()         在 maze_start_row 行搜索黑白跳变
       │  ├─ 左: 从中心向左扫描 白→黑 跳变
       │  └─ 右: 从中心向右扫描 黑→白 跳变
       │
validate_maze_start_pair()         左右起点间距 < 5px 则丢弃

```

**帧间历史自适应**：上一帧成功的起点 ±10px 偏移作为当前帧回退搜索中心。

### 3.4 阶段 3：边界追踪

位置：[vision_image_processor.cpp:3277-3650](../code/driver/vision/vision_image_processor.cpp#L3277-L3650)

由 `trace_left_boundary_selected_method()` / `trace_right_boundary_selected_method()` 根据 `g_maze_trace_method` 分发：

#### 分支 A：迷宫法 (mode=0)

| 函数 | 行号 | 机制 |
|------|------|------|
| `maze_trace_left_hand()` | 3004 | 4方向左手法则：前方有墙→右转，左前有墙→直行，否则→左转前进 |
| `maze_trace_right_hand()` | 3084 | 4方向右手法则：前方有墙→左转，右前有墙→直行，否则→右转前进 |

**特点**：不产生方向数组 (dir)，碰到 x=0/x=159 边框即停止。

#### 分支 B：八邻域法 (mode=1, 默认)

函数 `trace_boundary_eight_neighbor()` (第 3177 行)。

**种子搜索顺序** (第 595-614 行)：

```
左边界种子（逆时针）:  下→左下→左→左上→上→右上→右→右下
右边界种子（顺时针）:  下→右下→右→右上→上→左上→左→左下
```

**算法**：对每个候选方向，检查是否构成 2×2 wall-path 角点（当前方向是墙且下一个方向是路径），从有效候选中选 y 最小（最靠上）者，平局取方向索引较小的。每次步进记录 0-7 方向值，255 表示无有效后继。

#### 追踪输出数组

| `right_trace_pts[]` | 120 | 右侧追踪轮廓点 |
| `left_trace_dirs[]` | 120 | 左侧方向序列 (0-7 或 255) |
| `right_trace_dirs[]` | 120 | 右侧方向序列 |

### 3.9 阶段 8：line_error 计算

位置：[vision_image_processor.cpp:5461-5467](../code/driver/vision/vision_image_processor.cpp#L5461-L5467)

```c
line_error = vision_line_error_layer_compute_from_ipm_shifted_centerline(
    sel_ipm_x, sel_ipm_y, sel_ipm_count,    // ← IPM 坐标 (实际使用)
    sel_src_x, sel_src_y, sel_src_count,    // ← 原图坐标 (被 (void) 丢弃!)
    kIpmOutputWidth / 2);                   // ← 参考中心 = 80
```

**关键结论**：`line_error` 计算**只用 IPM 坐标**，`src_*` 三个参数在函数内部被 `(void)` 丢弃。返回值 = `(选中的 IPM 中线 x) - (参考中心 80)`，单位为 IPM 像素。

**4 种采样方法** (vision_line_error_layer.cpp)：

| 方法 | 枚举值 | 公式 |
|------|--------|------|
| `FIXED_INDEX` | 0 | 固定取第 N 个点 |
| `WEIGHTED_INDEX` | 1 | 多点前缀指数加权 (默认：索引 {8,12,16}，权重 {0.5,0.3,0.2}) |
| `SPEED_INDEX` | 2 | 动态索引 = k×speed + b |
| `WEIGHTED_SPEED_DELTA` | 3 | 兼容模式，同 WEIGHTED_INDEX |

## 4. 分支维度对链路的影响

### 4.1 二值化分支

- OTSU (默认)：全图单阈值，速度最快
- ADAPTIVE_MEAN：巡线时按需计算，略慢但适应光照不均
- ADAPTIVE_FULL：每像素自适应，最慢

### 4.2 追踪方法分支

- 迷宫法：无方向信息，跳过角点检测和所有状态机后处理 → **十字/圆环识别不工作**
- 八邻域 (默认)：产生方向序列，驱动完整的角点检测和状态机链路

### 4.3 状态机分支（影响边界重写）

- NORMAL：仅首次触边截断
- CROSS：3 阶段辅助边界+桥接+锚点裁剪
- CIRCLE：6 阶段 guide 线补线+替换对侧边界
- STRAIGHT：**枚举存在但无 handler，落到 default→NORMAL，实为死码**

### 4.4 IPM 中线源选择

- LEFT：基于左侧边界右移 → `g_ipm_shift_left_center_*`
- RIGHT：基于右侧边界左移 → `g_ipm_shift_right_center_*`
- AUTO (默认)：左右点数多者胜出

### 4.5 采样方法

- WEIGHTED_INDEX (默认)：多点前瞻，对弯道更平滑
- FIXED_INDEX：单点，抖动大
- SPEED_INDEX：速度自适应，高速看更远

## 5. 控制闭环读哪些视觉输出

`line_follow_thread.cpp` 读取 (详见 [当前代码视觉处理概述.md](./当前代码视觉处理概述.md))：

1. `line_error` → PID 转向控制
2. `track_point` (IPM 空间) → 角速度环目标
3. `route_main_state / route_sub_state` → 参数包选择 (Normal/CircleEnter/CircleInside/CircleExit)
4. `mean_abs_path_error` → 速度规划
5. `processed_frame_seq` → 帧新鲜度检测
