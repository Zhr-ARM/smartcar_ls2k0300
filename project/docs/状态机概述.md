# 状态机概述（按当前代码）

## 1. 核心位置

当前实际生效的路线状态机是 [project/code/driver/vision/vision_route_state_machine.cpp](../code/driver/vision/vision_route_state_machine.cpp)。

主链关系：

```
原图边界与特征 → route_state_machine → 边界修正与中线选边 → line_error → line_follow
```

## 2. 主状态与子状态

主状态枚举见 [vision_route_state_machine.h](../code/driver/vision/vision_route_state_machine.h#L6)：

| 枚举 | 值 | 说明 |
|------|-----|------|
| `VISION_ROUTE_MAIN_NORMAL` | 0 | 默认巡线 |
| `VISION_ROUTE_MAIN_CIRCLE` | 1 | 圆环（左/右由子状态区分） |
| `VISION_ROUTE_MAIN_STRAIGHT` | 2 | 直道（**预留枚举，无 handler，落到 default→NORMAL，当前为死码**） |
| `VISION_ROUTE_MAIN_CROSS` | 3 | 十字路口 |

子状态枚举见 [vision_route_state_machine.h](../code/driver/vision/vision_route_state_machine.h#L14)：

| 枚举 | 值 | 说明 |
|------|-----|------|
| `VISION_ROUTE_SUB_NONE` | 0 | 无子状态（NORMAL 时使用） |
| `VISION_ROUTE_SUB_CROSS_1` | 1 | 进入十字，检测到下角点 |
| `VISION_ROUTE_SUB_CROSS_2` | 2 | 十字中部，角点上浮 |
| `VISION_ROUTE_SUB_CROSS_3` | 3 | 十字深处，准备驶出 |
| `VISION_ROUTE_SUB_CIRCLE_LEFT_1~6` | 4-9 | 左圆环 6 阶段 |
| `VISION_ROUTE_SUB_CIRCLE_RIGHT_1~6` | 10-15 | 右圆环 6 阶段 |

说明：CIRCLE_LEFT 和 CIRCLE_RIGHT 不是独立主状态，而是共用 `VISION_ROUTE_MAIN_CIRCLE` 主状态，通过子状态值区分左右方向。

## 3. NORMAL 下入口优先级

当前代码优先级（[vision_route_state_machine.cpp:174-196](../code/driver/vision/vision_route_state_machine.cpp#L174-L196)）：

1. **CROSS** → `cross_entry_ready()`
2. **CIRCLE_LEFT** → `left_circle_entry_ready()`
3. **CIRCLE_RIGHT** → `right_circle_entry_ready()`

注意：STRAIGHT 没有入口检查——`VISION_ROUTE_MAIN_STRAIGHT` 枚举存在但在 switch 中无 case，落到 default 后直接回到 NORMAL。

## 4. 关键转移条件

### 4.1 NORMAL → CROSS_1

`cross_entry_ready(input)` 要求：

1. `route_cross_detection_enabled == true`
2. `left_corner_found == true`
3. `right_corner_found == true`
4. `left_corner_index >= 0`
5. `right_corner_index >= 0`
6. `left_corner_post_frame_wall_rows >= route_cross_entry_corner_post_frame_wall_rows_min`（默认 5）
7. `right_corner_post_frame_wall_rows >= route_cross_entry_corner_post_frame_wall_rows_min`（默认 5）

### 4.2 CROSS_1 → CROSS_2

`cross_stage2_ready(input)` 要求：

- 任一侧角点已找到且 `corner_y >= route_cross_stage1_enter_corner_y_min`（默认 75）

物理含义：角点在画面中"上浮"到一定高度，说明车已驶入十字足够深。

### 4.3 CROSS_2 → CROSS_3

`cross_stage3_ready(input)` 要求：

- `left_start_frame_wall_rows >= route_cross_stage2_enter_start_frame_wall_rows_min`（默认 1）
- `right_start_frame_wall_rows >= route_cross_stage2_enter_start_frame_wall_rows_min`（默认 1）

物理含义：左右原始 trace 起始段都开始贴边框，说明车已进入十字深处。

### 4.4 CROSS_3 → NORMAL

`cross_exit_ready(input)` 要求：

- `start_boundary_gap_x > 0`
- `start_boundary_gap_x < route_cross_exit_start_gap_x_max`（默认 155）

物理含义：左右边界起始点间距缩小到正常车道宽度，说明十字已过。

### 4.5 圆环主转移（左右镜像）

左圆环子状态推进条件：

1. `LEFT_1 → LEFT_2`：`left_start_frame_wall_rows >= route_circle_stage_frame_wall_rows_enter`（默认 30）
2. `LEFT_2 → LEFT_3`：`left_start_frame_wall_rows <= 0`
3. `LEFT_3 → LEFT_4`：`right_start_frame_wall_rows > route_circle_stage3_frame_wall_rows_trigger`（默认 70）
4. `LEFT_4 → LEFT_5`：`right_corner_found == true`
5. `LEFT_5 → LEFT_6`：`right_start_frame_wall_rows >= route_circle_stage_frame_wall_rows_enter`
6. `LEFT_6 → NORMAL`：`left_straight && right_straight`

右圆环按左右镜像，条件完全对称。

### 4.6 圆环入口条件

**左环** `left_circle_entry_ready()`：

1. `right_straight == true`
2. `left_corner_found == true`
3. `left_corner_y > route_circle_entry_corner_y_min`（默认 60）
4. `left_corner_index >= 0`
5. `right_boundary_count > route_circle_entry_min_boundary_count`（默认 20）
6. `left_circle_entry_raw_gap_ok == true`
7. `left_corner_index < (right_boundary_count - route_circle_entry_corner_tail_margin)`（默认 margin=20）

**右环**对称，左右互换。

## 8. preferred_source 含义与控制联动

状态机输出的 `preferred_source` 影响两个层面：

1. **边界补线方向**：`vision_image_processor.cpp` 中根据偏好源决定"单边丢线时用哪侧边界去补对侧"
2. **IPM 中线源选择**：`render_ipm_boundary_image_and_update_boundaries()` 中 `select_shift_source_from_preference_and_counts()` 决定基于哪侧边界生成平移中线

圆环状态的偏好源策略（刻意反向搭配）：

- 左圆环主状态默认 **RIGHT**，LEFT_3/4/5 阶段临时切到 LEFT
- 右圆环主状态默认 **LEFT**，RIGHT_3/4/5 阶段临时切到 RIGHT

line_follow 参数包选择（[line_follow_thread.cpp](../code/app/line_follow_thread/line_follow_thread.cpp)）：

- `CIRCLE_*_1` → CircleEnter
- `CIRCLE_*_2/3/4` → CircleInside
- `CIRCLE_*_5/6` → CircleExit
- 其他（NORMAL/CROSS/STRAIGHT） → NormalProfile
